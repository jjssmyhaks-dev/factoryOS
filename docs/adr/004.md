# ADR-004: Tally Bridge runtime — Node/TypeScript Windows service

- **Status**: accepted
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4
- **Context**: The bridge runs on customer Windows machines next to TallyPrime; install footprint and update reliability matter for non-technical users.
- **Decision**: **Node/TypeScript packaged as a Windows service** (tray UI), sharing `packages/connectors/tally` types with the cloud side.
- **Alternatives considered**: Go or .NET (smaller binary; revisit if install footprint or memory becomes a problem).
- **Consequences**: Node runtime must be bundled (or requires a runtime on the machine); IoT Jobs handles OTA updates.
- **Verification**: E4-S1 pairing < 5 min; E4-S6 version matrix spike.
