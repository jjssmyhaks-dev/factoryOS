# ADR-005: WhatsApp provider — Meta Cloud API via a BSP

- **Status**: accepted (BSP choice **[VERIFY]**)
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4
- **Context**: Two-way WhatsApp with interactive approval buttons is the primary channel (principle 3); Meta's Cloud API requires a BSP for most businesses.
- **Decision**: **Meta Cloud API via a Business Solution Provider**; pick the BSP after a 2-day spike (open question Q2) comparing embedded signup, pricing and template approval time.
- **Alternatives considered**: WhatsApp Business App + manual API (rejected: no programmatic interactive approvals); unofficial APIs (rejected: ban risk).
- **Consequences**: outbound messaging service must abstract BSP specifics (§8.4); per-message fees metered per tenant (§4.3).
- **Verification**: spike comparing BSPs; template approval time test in E5.
