# ADR-006: GSP vendor for e-invoice and e-way bill (Phase 2)

- **Status**: proposed (decide before Phase 2)
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4
- **Context**: Phase 2 (E22) needs IRN generation and e-way bills through an authorized GST Suvidha Provider.
- **Decision**: **Decide after a vendor spike [VERIFY]** — evaluate on IRN latency, sandbox quality, pricing per document, uptime SLA, and webhook support.
- **Alternatives considered**: direct IRP integration (rejected: GSP is the authorized path for MSME tooling).
- **Consequences**: connector interface (§8.1) already abstracts write-back, so swapping GSPs later is configuration + adapter work.
- **Verification**: vendor spike scheduled before Phase 2 starts (Q4).
