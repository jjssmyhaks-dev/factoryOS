# ADR-012: API framework — Hono on Lambda

- **Status**: accepted
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4
- **Context**: API Gateway HTTP API → Lambda; bundle size and cold starts are on the critical path (NFR-14); routes must be zod-validated with generated OpenAPI.
- **Decision**: **Hono on Lambda behind API Gateway HTTP API**, zod-validated routes, generated OpenAPI. NestJS remains possible through a Lambda adapter at the cost of bundle size and cold starts.
- **Alternatives considered**: NestJS (rejected for bundle size/cold start); plain `@aws-lambda/api` handlers (rejected: no ergonomic middleware/routing).
- **Consequences**: middleware chain carries tenant context (JWT → `set_config`), request_id, and permission checks; OpenAPI generated from route schemas.
- **Verification**: p95 ≤ 500 ms non-LLM endpoints (NFR-1); cold-start budget (NFR-14).
