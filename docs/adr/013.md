# ADR-013: IaC and web deployment — SST v3 with OpenNext

- **Status**: accepted (provisional pending one-day spike — see `docs/spikes/0001-sst-vs-cdk.md`)
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4 / Q10
- **Context**: Serverless-only policy (§4.2) needs IaC that covers Lambda, SQS, EventBridge, Step Functions, IoT Core, plus Next.js on Lambda+CloudFront+S3.
- **Decision**: **SST v3 (TypeScript) with OpenNext for the web apps**; AWS CDK as fallback, decided by a one-day spike (E0-S2) **[VERIFY current maturity]**.
- **Alternatives considered**: CDK alone (more boilerplate for Next.js); Serverless Framework (YAML, weaker TS typing); Terraform (wrong abstraction level for app-adjacent resources).
- **Consequences**: `infra/` is the only place allowed to create cloud resources; NFR-16 policy check runs in CI over `infra/`.
- **Verification**: spike doc; ephemeral per-PR stages (E0-S2).
