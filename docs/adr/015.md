# ADR-015: Serverless exceptions — run-to-completion Fargate only

- **Status**: accepted
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.2
- **Context**: Some jobs exceed Lambda's 15-minute timeout or container-image limits: the Phase 3 scheduling solver, bulk migrations, very large document batches.
- **Decision**: **Fargate tasks launched by a workflow are allowed for run-to-completion work only.** EC2, EKS, always-on ECS/Fargate services, and self-hosted Redis/Kafka/ClickHouse require an ADR.
- **Alternatives considered**: Lambda with 15-min cap + step splitting (default; used wherever possible); Batch (rejected: heavier operational surface).
- **Consequences**: `scripts/check-serverless-policy.ts` enforces this in CI; a file may carry `// serverless-exception: ADR-0xx` only when the ADR file exists.
- **Verification**: CI policy check green (NFR-16).
