# ADR-008: LLM observability — in-house trace store + OpenTelemetry

- **Status**: accepted
- **Date**: 2026-09-21
- **Deciders**: founder (SRB), PRD §4.4
- **Context**: Traces must satisfy two audiences (§7.1), keep tenant data in-region, and fit the serverless policy.
- **Decision**: **In-house trace store (`agent_runs`, `agent_steps` in Postgres, large payloads in S3) plus OpenTelemetry (ADOT Lambda layer) to X-Ray and CloudWatch.** Langfuse is optional later: self-hosting it is not serverless, and its hosted region must be checked against residency **[VERIFY]**.
- **Alternatives considered**: Langfuse hosted (residency + cost at low volume); Helicone/LangSmith (same residency question).
- **Consequences**: we own the redaction layer and the run explorer's data source; no vendor lock-in for traces.
- **Verification**: E7-S1 span attributes emitted end to end; redaction tests.
